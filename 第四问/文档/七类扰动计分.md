# 第四问代表场景计分

A021 表 5a 根据无门限连续时间轴统计七类扰动的固定计划漏项数。复现程序按“连续分支定界”标签读取输入，在开始计分前核对无门限及 1 m 两份 CSV 的 SHA-256、基准站址与开测时刻，分别运行圆环覆盖校验器。输入签名和六种故障状态（含无故障）的时间上界打印到终端。

在项目根目录运行以下命令，仅需 Python 标准库。加上输出参数可重新生成逐场记录。

```powershell
py -3 -B -X utf8 "第四问/代码/q4_table5a.py" --output "第四问/文档/A021代表场景复算.csv"
```

599 场中，固定计划有 208 场漏一项、384 场漏两项、7 场全部开测。对 576 个有新增告警的场景，证书直接保证四项全开测。对无新增但有漏项的 16 场，四项任务的已验证可行时间表投影到三项原告警即可保留满分保证。其余 7 场采用固定计划。新增任务连续变化时，无门限与 1 m 证书的最坏时间上界分别为 48.975805 s 和 59.998799 s。

[逐场计数](A021代表场景复算.csv)给出固定计划的计分时刻和证书保证的开测数。完整基准时间轴和[证书附件](A019复核附件/复核说明.md)用于复核。A019 代表场景附件和旧版逐车轨迹是历史实验；其中的改派时刻属于其原实验。
