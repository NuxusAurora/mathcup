## A 连续站址求解

在项目根目录运行。求解依赖 Python、NumPy 和 SciPy。输出目录须尚未存在。

```powershell
py -3.14 -B -X utf8 "第四问/代码/q4_reschedule.py" --output "第四问/文档/连续选站复跑"
```

默认求解表 5a 的 599 场。加 `--scene N0255` 可只求指定场景，参数可以重复。加 `--verify` 并指定已有结果目录，可重新读取 CSV 并核对计分和逐车轨迹。复核单场目录时也须传入对应场景编号。

程序读取连续初始时间轴，使用既有证书中的排程和原表站址初始化。依次试通信恢复、原表在恢复后即将开测的时点和第 35 秒，从当时的位置、车组和复位状态重放候选。对每个试算时点的最佳可行候选，沿连续方向做有界线搜索。每次更新按连续坐标重算行驶、指向、双车同步和复位，并检查全程车辆间距。车组、任务顺序和绕障路径由证书模板及其重放确定，局部搜索保留所选路径的绕障拐点。

成绩表和逐车时间轴通过复核后一起写入。复核检查输入签名、故障退出、通信恢复前的固定前缀、路线及视线净空、双车同步和计分。输出表可通过固定与重调度的时间轴编号查到每辆车的站址、路线和各阶段时刻。

本次 599 场均满分。相对固定计划，208 场多开测一项，384 场多开测两项，7 场平。最慢的可行排程是 N0255，最晚开测约 36.168754 s。以 1 μs 为比较容差，相对旧 A019 的逐场结果，本轮有 53 场更早、127 场相同、419 场更晚。

程序同时输出满分所需的最晚开测下界和间隙。若到首个可改派时刻前还有告警未开测，最晚开测至少到该时刻。若全部已开测，固定前缀中的最后一次开测时刻就是下界。N0002、N0003、N0022、N0023 的上下界相合，最晚开测均为 10.352118549 s。N0255 的区间为 [30, 36.168754] s。要进一步证明时间最优，需要对全部车组、任务顺序、改派时刻、站址和路线定界。

## B 连续站址与偏移复核

B 读取最新版实际约束时间轴的车组、路点和站址，按第二问的最坏行驶、指向和复位时间重放固定指令。每个非零行驶段预留两端共 0.20 m 的长度增量，早到车辆可在终点等待。第二问导出的是标称时间轴，第四问 B 的原表开测与复位采用上述时序的保证值。

改派保留各健康车辆的原表路线与复位时段。在通信允许且车辆完成最后一项原表指令后，程序从其保守停车状态出发。初始车组和站址来自已交付模板与 B 原表。搜索可交换健康车辆、改变任务顺序，并沿连续坐标细化站址。验证用路线及视线净空扣除偏移，用重叠时段内的路段空间最小间距扣除两车各 0.10 m 偏移，并沿用第二问的一阶 RMS 上界。故障车在第 5 秒退出，未开测的失配原表任务保留健康车的占用时间，计分置空。

在项目根目录运行以下命令。输出 CSV 分别记录逐场计分与逐车指令时间，按时间轴 ID 关联。部分场景可重复使用 `--scene` 指定，独立复核也使用相同场景选择。

```powershell
py -3.14 -B -X utf8 "第四问/代码/q4_robust.py" --output "第四问/文档/B实际约束复跑"
py -3.14 -B -X utf8 "第四问/代码/q4_robust.py" --verify --output "第四问/文档/B实际约束结果"
```

## A021 历史证书复算

A021 表 5a 根据无门限连续时间轴统计七类扰动的固定计划漏项数。复现程序按“连续分支定界”标签读取输入，在开始计分前核对无门限及 1 m 两份 CSV 的 SHA-256、基准站址与开测时刻，分别运行圆环覆盖校验器。输入签名和六种故障状态（含无故障）的时间上界打印到终端。

在项目根目录运行以下命令，仅需 Python 标准库。加上输出参数可重新生成逐场记录。

```powershell
py -3 -B -X utf8 "第四问/代码/q4_table5a.py" --output "第四问/文档/A021代表场景复算.csv"
```

599 场中，固定计划有 208 场漏一项、384 场漏两项、7 场全部开测。对 576 个有新增告警的场景，证书直接保证四项全开测。对无新增但有漏项的 16 场，四项任务的已验证可行时间表投影到三项原告警即可保留满分保证。其余 7 场采用固定计划。新增任务连续变化时，无门限与 1 m 证书的最坏时间上界分别为 48.975805 s 和 59.998799 s。

[逐场计数](A021代表场景复算.csv)给出固定计划的计分时刻和证书保证的开测数。完整基准时间轴和[证书附件](A019复核附件/复核说明.md)用于复核。A019 代表场景附件和旧版逐车轨迹是历史实验；其中的改派时刻属于其原实验。
