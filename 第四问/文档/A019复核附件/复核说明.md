# A019 第四问复核说明

两套覆盖结果均以第二问连续分支定界的导出时间轴为输入。证书内记录输入文件名称及 SHA-256。给定故障状态和新增告警的平面位置，查找覆盖该位置的闭方格，再按方格引用的排程选取车组、路线和站址。

- [代表场景成绩](A019代表场景成绩.csv)包括无门限组 599 个场景。按固定或重调度时间轴编号查[逐车时间轴](A019逐车时间轴.csv)。598 套时间轴覆盖固定状态与全部改派样本。
- [无门限覆盖证书](q4_nominal_certificate.json)与 [1 m 覆盖证书](q4_1m_certificate.json)分别验证连续闭圆环。统一在第 35 秒改派，包含无故障和五种单车故障。六种状态均能在 60 秒内开始全部四项观测。
- 最晚开测的保证上界分别为 48.975805 秒和 59.998799 秒。1 m 组四项观测的局部水平定位均方根误差不超过 0.999999978 m。

在本目录运行下列命令即可独立复核两套覆盖证书。校验器只使用 Python 标准库。

```powershell
py -3 -B -X utf8 verify_q4.py q4_nominal_certificate.json
py -3 -B -X utf8 verify_q4.py q4_1m_certificate.json
```
