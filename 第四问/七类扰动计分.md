# 第四问｜固定原计划的七类场景

沿用解释 B。通信于第 5 秒中断；持续 5、15、30 秒分别于第 10、20、35 秒恢复。以下推导适用的基准策略在第 0 秒已下发全部原计划，新增告警没有预先指派的车辆。计分只要求在闭区间 [0,60] 秒内开始观测。

记 q 为第 5 秒前已经开始观测的原告警数。完成一次联合观测占用两台车 5 秒，所以同一台车不能在前 5 秒开始两项观测。五台车决定了 q ≤ 2。恰在第 5 秒开始的告警按既有约定先处理扰动，不计入 q。令 U(q) = q + 0.6(3−q)。

| 扰动 | 原计划完成率 η | 最晚开始时间 |
|---|---|---|
| 仅新增 | 至多 3/4 | 60 s |
| 仅故障 | E[η] ≤ U(q)/3 | 有漏项时为 60 s |
| 仅通信中断 | 与无扰动原计划相同 | 与无扰动原计划相同 |
| 新增＋故障 | E[η] ≤ U(q)/4 | 60 s |
| 新增＋中断 | 至多 3/4 | 60 s |
| 故障＋中断 | E[η] ≤ U(q)/3 | 有漏项时为 60 s |
| 新增＋故障＋中断 | E[η] ≤ U(q)/4 | 60 s |

**故障上界的依据。** 对每个尚未开始的原告警，两台指定车辆都避开故障的概率恰为 3/5。计入成功还依赖前序任务、同步与时限，故每项成功概率至多为 3/5。用期望的可加性求和即可，不要求不同告警的成功事件独立。若 q = 0，故障场景的平均完成率上限为 60%，再加新增告警则降至 45%。表中的期望仅对五种等概率故障身份取平均，不是单个故障场景的成绩。
