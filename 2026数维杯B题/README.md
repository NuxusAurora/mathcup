# 2026 数维杯 B 题 · 多移动观测车协同的无人机目标快速定位

本目录为 2026 年数维杯 B 题的完整成果：LaTeX 论文源码、四问求解代码、结果 CSV 与全部图件。

## 目录

```
2026数维杯B题/
├── 论文/                 LaTeX 源码（XeLaTeX 编译）+ 论文.pdf
│   ├── 论文.tex          主文件
│   ├── format.cls        排版类（数维杯模板）
│   └── 0.摘要.tex ... 11.附录.tex   各章节
└── 求解/
    ├── _common.py        公共工具（字体、配色、出图、CSV）
    ├── _geometry.py      公共几何（建筑、可观测性、slab 判定）
    ├── 问题一/           可观测区域与最优观测站
    ├── 问题二/           双站交会精度 + 并发调度
    ├── 问题三/           误差传播与蒙特卡洛验证
    └── 问题四/           扰动重调度与场景比较
```

## 编译

```bash
cd 论文
xelatex 论文.tex
xelatex 论文.tex     # 第二遍用于目录与交叉引用
```

**字体未随仓库分发**（体积与授权原因）。缺少时请自备并放入 `论文/fonts/`：

- `SourceHanSerifCN-Regular.otf` / `SourceHanSerifCN-Bold.otf`（思源宋体，OFL 许可）
- `SIMLI.TTF`（隶书，仅 Windows 自带，不可再分发）
